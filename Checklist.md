# Airline Reservation System Requirements

## 1. User Functionality
**(20 points)**

### Flight Search & Browsing
- [] **Search Flights:** Allow users to search for flights between two airports.
    - [] One-way on a specific date.
    - [] Round-trip on specific dates.
    - [] Flexible dates (+/- 3 days) for one-way or round-trip.
- [] **Browse Results:** View the resulting list of available flights.
- [] **Sort Flights:** Ability to sort by:
    - Price
    - Take-off time
    - Landing time
    - Flight duration
- [] **Filter Flights:** Ability to filter by:
    - Price range
    - Number of stops
    - Airline
    - Take-off time
    - Landing time

### Reservations & Account Management
**(20 points)**
- [ ] **Booking:** Make flight reservations and purchase tickets.
- [ ] **Waiting List:** Option to enter a waiting list if a flight is full.
- [ ] **History:** View all past flight reservations with full details.
- [ ] **Upcoming:** View all upcoming flight reservations with full details.
- [ ] **Cancellation:** Cancel reservations (restricted to Business or First Class).
- [ ] **Notifications:** Automatically send alerts to customers on the waiting list when a seat becomes available.
- [ ] **Support:** Post questions to a customer representative.

---

## 2. Admin Functionality
*Pre-requisite: Create a master admin account ahead of time.*
**(20 points)**

- [ ] **User Management:** Add, Edit, and Delete customer representative or customer accounts.
- [ ] **Sales Reports:** Obtain a sales report for a specific month.
- [ ] **Reservation Lists:** Produce a list of reservations filtered by Flight Number or Customer Name.
- [ ] **Revenue Summaries:** Produce a summary of revenue generated by:
    - A particular flight
    - A specific airline
    - A specific customer
- [ ] **Analytics - Top Customer:** Identify the customer who generated the most total revenue.
- [ ] **Analytics - Top Flights:** Produce a list of most active flights (highest number of tickets sold).

---

## 3. Customer Representative
**(20 points)**

- [ ] **Assisted Booking:** Make flight reservations on behalf of users.
- [ ] **Reservation Management:** Edit existing flight reservations for customers.
- [ ] **Infrastructure Management:** Add, Edit, and Delete information for:
    - Aircrafts
    - Airports
    - Flights
- [ ] **Waiting List Access:** Retrieve a list of all passengers currently on the waiting list for a specific flight.
- [ ] **Airport Traffic:** Produce a list of all flights (arriving and departing) for a given airport.
- [ ] **Communication:** Reply to questions posted by users.
